A widget is not a fix

Most ADA website complaints are filed against online stores, and a settlement usually comes with a deadline to make the site usable with a screen reader and a keyboard. Overlay widgets don't change the code that screen readers read. The FTC fined one overlay vendor $1 million in 2025 over its claims, and stores with overlays installed keep getting sued.

Tabstop edits the code your theme actually ships: button names, form labels, focus order, contrast, image text, headings and the cart.

What the free report looks like

Questions

We already have an accessibility widget. Isn't that enough?

No. Widgets add a toolbar on top of the page but leave the underlying code as it is, and that code is what a screen reader reads. You can keep or remove the widget; our fixes don't depend on it.

Do you need access to our Shopify admin?

No. You send the theme file and upload the fixed copy yourself. If you prefer, you can add us as a collaborator instead.

Our theme was customized by an agency. Does that matter?

We work on the code as it is today, customizations included. If the theme is unusually large, we tell you before you pay and quote a fixed price for it.

When do we pay?

After you've seen the free report and agreed to the scope. Payment is by card through a Stripe link.
